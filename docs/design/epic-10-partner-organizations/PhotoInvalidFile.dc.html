How a photo goes up

1

Choose a file

JPEG, PNG or WebP, straight from the camera — no need to prepare it.

2

Frame it

Drag and zoom inside a fixed 3 : 2 frame, the shape of the lounge photos.

3

Pick a size

Large, Standard or Light, with the weight each will have.

4

Upload

Only the cropped, compressed photo leaves the browser.

The editor doesn't open for a file that isn't an image. A damaged image gets the same message: “… can't be read”.

The message stays until another file is chosen; the photos already there don't change.
