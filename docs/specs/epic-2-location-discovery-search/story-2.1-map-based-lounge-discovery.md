# Story 2.1: Map-Based Lounge Discovery

## User Story
As a member, I want to see nearby luxury lounges on a map so that I can find the perfect space for my needs.

## Acceptance Criteria
- [ ] Interactive map showing user's current location
- [ ] Lounge markers with custom En Soleil branding - Yes
- [ ] Distance display in miles/km based on user preference (phone setup)
- [ ] Map zooming and panning functionality
- [ ] Current location detection with permission request
- [ ] Fallback to manual location entry if GPS unavailable
- [ ] Map loads within 3 seconds on good connection
- [ ] Offline mode shows cached nearby locations
