# Story 7.1: Daily Guest Management

## User Story
As a lounge partner, I want to view today's expected guests so that I can prepare for arrivals and provide excellent service.

## Acceptance Criteria
- [ ] Today's guest list
- [ ] Guest details: name, contact, email
- [ ] Real-time updates when new bookings are made
- [ ] Check-in status tracking for each guest (box with showed up yes/no)
- [ ] No-show reporting functionality
- [ ] Guest contact information for communication
- [ ] Print-friendly guest list format CSV
- [ ] Search/filter guests by name or date
