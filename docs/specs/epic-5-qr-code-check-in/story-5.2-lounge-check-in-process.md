# Story 5.2: Lounge Check-In Process

## User Story
As a member, I want to check in quickly at the lounge so that I can start enjoying the space immediately.

## Acceptance Criteria
- [ ] Instant verification of booking validity
- [ ] Check-in confirmation to member's app
- [ ] No-show tracking for booking history
- [ ] Emergency contact information accessible to staff
