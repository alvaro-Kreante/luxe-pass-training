# Story 4.1: Seamless Booking Flow

## User Story
As a member, I want to book a lounge visit easily so that I can secure my luxury space access.

## Acceptance Criteria
- [ ] Date picker starting from today
- [ ] Admission for one ONLY
- [ ] Special requests/notes field (100 char limit)
- [ ] Booking summary before confirmation
- [ ] Terms and cancellation policy display
- [ ] One-tap booking confirmation
- [ ] Immediate booking confirmation screen
- [ ] If full option to be on the waitlist
