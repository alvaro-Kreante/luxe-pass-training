# Story 8.4: Bookings Overview

## User Story
As an admin, I want to see every booking across the network by date and lounge so that I know who is coming, where and at what time, and can act on a booking without first finding the member.

## Acceptance Criteria
- [ ] Bookings list for a chosen date, opening on today
- [ ] Move to the previous or next day without leaving the screen
- [ ] Filter by lounge (or all lounges)
- [ ] Filter by status: confirmed, checked in, no-show, cancelled
- [ ] Search by booking reference or member name
- [ ] Bookings grouped by arrival time, with the number of bookings for each arrival time
- [ ] With one lounge selected, seats taken vs. capacity for each band (morning, afternoon, evening)
- [ ] Each booking shows arrival time, member, reference, lounge and status
- [ ] Opening a booking gives access to the existing booking modification (reschedule, cancel)
- [ ] Only admins can see this list
