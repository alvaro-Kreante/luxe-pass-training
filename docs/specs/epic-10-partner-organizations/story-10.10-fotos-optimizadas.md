# Story 10.10: El admin recorta y redimensiona las fotos del lounge

## User Story
Como admin, quiero recortar y redimensionar cada foto del lounge antes de subirla, para elegir el encuadre y que la app cargue rápido sin preparar las imágenes fuera.

## Acceptance Criteria
- [ ] Al elegir una foto al crear o editar un lounge, se abre un editor antes de subirla
- [ ] En el editor, el admin puede mover y hacer zoom para elegir el encuadre, con la proporción fija de las fotos del lounge
- [ ] El admin puede elegir el tamaño final entre varias opciones, y ve el peso estimado del resultado
- [ ] Al confirmar, se sube la versión recortada y comprimida, no el original
- [ ] Cancelar el editor no sube nada
- [ ] Una foto ya subida se puede volver a abrir en el editor para cambiar su encuadre
- [ ] Un archivo que no es una imagen se rechaza con un mensaje claro
- [ ] El admin ve el progreso mientras se sube cada foto
