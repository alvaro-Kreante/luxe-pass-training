# Story 6.3: Member Profile & Preferences

## User Story
As a member, I want to manage my profile and preferences so that I receive a personalized experience.

## Acceptance Criteria
- [ ] Edit profile all fields input before
- [ ] Favorite lounges list
- [ ] Preferred amenities selection
- [ ] Membership status Active/Inactive
- [ ] Referral code sharing functionality
- [ ] Privacy settings for data usage
- [ ] Account deletion option with confirmation
- [ ] Export personal data option (GDPR compliance)
