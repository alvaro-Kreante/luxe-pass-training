# Story 3.1: Detailed Lounge Information

## User Story
As a member, I want to view comprehensive lounge details so that I can make an informed booking decision.

## Acceptance Criteria
- [ ] High-quality hero image carousel (min 3 images)
- [ ] Lounge name, address, and contact information
- [ ] Operating hours display with today's hours highlighted
- [ ] Amenity icons with descriptions
- [ ] User ratings and review count (if available)
- [ ] Call and Directions quick action buttons (google maps url)
- [ ] Share lounge option via social/messaging apps
