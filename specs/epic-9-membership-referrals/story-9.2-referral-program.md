# Story 9.2: Referral Program

## User Story
As a member, I want to refer friends and earn rewards so that I can share Luxe Pass and benefit from referrals.

## Acceptance Criteria
- [ ] Unique referral code generation
- [ ] Easy sharing via social media, email, SMS
- [ ] Referral tracking and status updates
- [ ] Reward crediting for successful referrals (pending)
- [ ] Friend's sign up confirmation notification
- [ ] Referral bonus terms and conditions
