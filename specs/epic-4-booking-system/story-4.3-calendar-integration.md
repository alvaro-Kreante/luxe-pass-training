# Story 4.3: Calendar Integration

## User Story
As a member, I want to add my booking to my calendar so that I don't forget my lounge visit.

## Acceptance Criteria
- [ ] Add to Calendar option post-booking
- [ ] Support for iOS Calendar, Google Calendar, Outlook ics file
- [ ] Pre-populated event with lounge details and address
- [ ] 15-minute reminder notification default
- [ ] Directions link included in calendar event
- [ ] Booking reference number in event description
