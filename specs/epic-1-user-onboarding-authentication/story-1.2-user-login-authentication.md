# Story 1.2: User Login & Authentication

## User Story
As a registered member, I want to securely log into my account so that I can access my bookings and preferences.

## Acceptance Criteria
- [ ] User can login with email/password
- [ ] Remember me functionality for convenience
- [ ] Password reset via email with secure token
- [ ] Account lockout after 5 failed attempts (15min timeout)
- [ ] Automatic logout after 30 days of inactivity
- [ ] Clear error messages for invalid credentials
