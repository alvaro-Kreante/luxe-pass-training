# Story 2.2: Lounge Filtering & Search

## User Story
As a member, I want to filter lounges by amenities and preferences so that I can find spaces that meet my specific needs.

## Acceptance Criteria
- [ ] Filter by amenities: WiFi, Lounge, Spa, Co-working, Day Rooms (at hotels), Luggage storage
- [ ] Filter by distance: <0.5mi, <1mi, <2mi, <5mi
- [ ] Filter by availability: Calendar view
- [ ] Text search by lounge name or location or amenities
- [ ] Clear all filters option
- [ ] Filter results update in real-time
- [ ] No results state with suggestions to modify filters
