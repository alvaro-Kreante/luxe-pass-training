# Story 7.2: Booking Notifications for Partners

## User Story
As a lounge partner, I want to receive booking notifications so that I'm always aware of upcoming guests.

## Acceptance Criteria
- [ ] Email notification for each new booking
- [ ] Morning digest email with day's guest list
- [ ] Cancellation notifications with updated guest count
