# Story 2.3: List View Alternative

## User Story
As a member, I want to view lounges in a list format so that I can quickly scan options without using the map.

## Acceptance Criteria
- [ ] Toggle between Map and List view
- [ ] List sorted by distance (closest first)
- [ ] Each item shows: name, distance, amenity icons, availability
- [ ] Lounge images as thumbnails
- [ ] Tap to view lounge details
- [ ] Infinite scroll for large lists
- [ ] Loading states while fetching data
