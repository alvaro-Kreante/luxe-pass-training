# Story 5.1: Digital Pass Generation

## User Story
As a member, I want to receive an email with my booking info so that I can check in at the lounge seamlessly.

## Acceptance Criteria
- [ ] Unique confirmation number generated for each booking LP#
- [ ] Information displays: member name, lounge name, date/time, duration
- [ ] Information available from My Bookings section
- [ ] Screenshot-friendly design for easy saving
- [ ] Booking expires automatically after booking window
