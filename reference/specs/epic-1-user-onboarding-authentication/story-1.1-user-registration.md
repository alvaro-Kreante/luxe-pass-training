# Story 1.1: User Registration

## User Story
As a potential member, I want to create an account easily so that I can access luxury lounge bookings.

## Acceptance Criteria
- [ ] User can register with email and password
- [ ] Email verification required before account activation
- [ ] Password must meet security requirements (8+ chars, special characters)
- [ ] User receives welcome email with app download links
- [ ] Profile creation includes: name*, phone*, profile photo, interests, location*, cities where they travel the most, job position, Industry*, Company, DOB (just day/month)
- [ ] Terms of service and privacy policy acceptance required
- [ ] Duplicate email addresses are prevented with clear error messaging
