# Story 3.2: Availability

## User Story
As a member, I want to see current availability and capacity so that I can plan my visit effectively.

## Acceptance Criteria
- [ ] Real-time availability status: Available / Not Available
- [ ] Weekly availability calendar view
- [ ] Booking restrictions display (member tier, advance notice)
- [ ] Holiday/special event closure notifications
- [ ] Last updated timestamp for availability data
- [ ] Automatic refresh every 5 minutes
